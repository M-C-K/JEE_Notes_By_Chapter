# JEE Advanced Prep App

A React app for JEE Advanced preparation with quiz practice and concept notes.

## Features
- **Quiz Practice** — 90 JEE Advanced questions across Physics, Chemistry, Mathematics
- **Concept Notes** — 58 chapters, 232 concepts with mind maps and reference sheets
- **3-page notes** — Mind map · Reference sheet · Memory anchors (printable PDF)
- **Dashboard** — Chapter clarity scores and progress tracking

## Run Locally

```bash
npm install
npm run dev
```

## Deploy to GitHub Pages / Netlify / Vercel

```bash
npm run build
# Upload the dist/ folder to your host
```

## Tech Stack
- React 18
- Recharts (dashboard charts)
- Vite (build tool)
